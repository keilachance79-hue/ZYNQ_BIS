# 硬件重点问题：上板验收前必须关闭

更新：2026-10-09。**以下全部为 OPEN / NEED_CONFIRMATION，不能因数字仿真通过而关闭。**Phase5 数字扫描控制已验证，此状态不代表板级验收通过。

| 优先级 / ID | 已确认事实与影响 | 建议措施 | 关闭证据 |
|---|---|---|---|
| P0 / HW-CLK | AD9269 CLK± 由 CN1 直连核心板，相关 Bank 默认 3.3 V；不能直接送入 3.3 V 方波。CLK− 所接 U13 还有 1 kΩ 下拉 | 候选 SN65LVDS1DBVR：3.3 V 供电、接收 FPGA 同源时钟、输出 LVDS，经终端及交流耦合接 ADC；隔离旧直连及 ADC 侧的 U13 下拉影响 | 修订原理图/PCB、装配记录、ADC 引脚处幅度/共模/过冲/占空比/抖动及 DAC/ADC 时基关系 |
| P0 / HW-RBIAS | R148 值、器件料号均为 510 kΩ，并接 U64.58 RBIAS 到地；器件要求 10 kΩ、1% | 同时更正阻值、器件及采购料号和 BOM，核验实物 | 修改后的 EDA/BOM、装配与实测记录 |
| P1 / HW-DCO | DCOA→W8、DCOB→U8，均非 SRCC/MRCC；现有双 DCO 接收尚无板级布线及时序证据 | 优先评估改接合适时钟脚；公共时钟采样属于待重新验证的替代架构，不自动替换用户要求的 DCO 接收 | 确定接线、真实 XDC、布局布线时序/CDC、台架数据完整性和两通道对齐 |

| P1 / HW-MAP | 用户已确认 E1→DB1 顺次；PCB 网络审计发现 I− A0=B35_L23P、A1=B35_L23N，与旧 PDF 整理表顺序相反 | 按 [Phase5 映射](../Phase5/docs/electrode_map.md)核对实物与最终 XDC，勿套用历史表 | 线束/连接器/20 条地址线导通与实际选通验证 |

SN65LVDS1DBVR 是已核对电平条件的改板候选，**尚未采购/安装或实测批准，也不是抖动清理器**。基本连接：D 接 FPGA 3.3 V 时钟；VCC=3.3 V、就近 100 nF 去耦；Y/Z 之间 100 Ω，置于两只 100 nF 串联耦合电容的驱动器侧，靠近 ADC；电容另一端分别接 CLK+/CLK−。需断开旧 CLK± 直连，保留核心板配置侧所需的下拉。布线、启动和波形仍需验证。

ADA4938-2 是 VIN± 模拟信号驱动器，不代表 CLK± 时钟适配已经完成。
