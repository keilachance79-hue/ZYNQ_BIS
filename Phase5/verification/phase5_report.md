总计 **26,432 对样本**逐点一致。全部扫描请求按独立 Python 表核对四电极、四地址、索引、帧 ID、起始 tag 与校准 ID；同时验证环回、无电流/电压电极重合、settling 下限、period 对齐，以及缓存输出受反压时的数据/描述符保持。

联合仿真直接实例化未修改的 `Phase2/rtl/adc_frame_buffer.sv`。理想 V/I 样本每 4 个 DSP 周期提供一对，接收器每 8 周期读一对，前 650 周期禁止读取以耗尽两个缓存；16 点测试均观察到 256 个 buffer wait 周期。为缩短全表回归，928/208 全扫描采用 16 点帧；另用 2048 点帧完成 4 电极一轮，防止只验证缩小参数。并未运行全部 928 次 2048 点 FFT/CORDIC。

12 组控制场景：启动资格不足；运行中资格丢失；abort；采集故障；等待缓存超时；等待采集完成超时；请求 epoch 过期；完成计数异常；tag 回绕及优雅停止/配置锁存；停止后重启时 ID 连续；settling 中复位；请求阶段复位。故障粘滞并阻止新增预约。未穷举所有参数组合或内部状态位翻转。

仅控制器（含映射逻辑）的 OOC 综合占用 **248 LUT、328 FF、0 DSP、0 BRAM tile**；缓存资源不包含在该数字中。内部 WNS **+4.376 ns**、TNS 0、WHS **+0.246 ns**。见 [资源](utilization_synth.rpt)、[时序](timing_synth.rpt)、[DRC](drc_synth.rpt)。

OOC 没有板级输入/输出延迟和 HD.CLK_SRC；ZPS7-1 Warning 表示需要集成 PS7，不能视为可下载整机。内部时序通过不代表外部地址偏斜、MUX 模拟瞬态、ADC 同步或整机吞吐已验证。源码指纹按 LF 换行归一化，包含参与仿真的 Phase2 帧缓存。

硬件事实：四片 CS/WR/EN 均接地；用户确认电极顺序；I− A0/A1 的当前 EDA 接线与历史 PDF 整理表顺序不同。闭环要求详见 [未决问题](../docs/open_issues.md)。原始 EDA 与 Phase0..4 源码和验证数据未改写。
