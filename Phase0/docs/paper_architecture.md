## 2. 数据链路与 multisine generation

论文事实：预先设计等幅、非等间隔频点的一个周期 multisine，使用 crest-factor minimization 算法降低峰均比，将离散波形存 ROM，由地址累加器顺序播放。不是 PL 内多个实时 DDS 相加。

```text
预生成 LUT -> 2048×16 bit ROM -> 地址累加器 -> LTC1668 -> LPF -> MCS
                                                              |
                          I+/I- MUX -> 被测对象 -> V+/V- MUX -> 放大
                                                              |
                         ADC -> FIFO -> FFT -> CORDIC -> PS -> PC
```

ROM 实际应理解为 2048 个 16-bit 样点，即 4096 bytes。原文/图中“16-bit × 2048 bytes”表述混用了位宽与容量，不能照字面分配 32768 bytes。

| k（从 0 起） | q / FFT bin | f（Hz） |
|---|---:|---:|
| 0 | 2 | 10000 |
| 1 | 3 | 15000 |
| 2 | 7 | 35000 |
| 3 | 11 | 55000 |
| 4 | 19 | 95000 |
| 5 | 37 | 185000 |
| 6 | 61 | 305000 |
| 7 | 113 | 565000 |
| 8 | 199 | 995000 |

本项目要求：`FS_HZ=10240000`、`ROM_LENGTH=2048` 为统一配置源；`x[n]=Σ Ak sin(2πqk n/N+φk)`；第一版等幅；Python 生成 `.hex/.coe`。后续 PS→AXI→BRAM 为独立升级。

建议实现：固定随机种子，多初值相位优化，最小化 `max(abs(x))/rms(x)`，保持频率/幅值约束。记录优化前后 CF、每频点相位、全局缩放、量化误差及文件 hash。CF 优化需过采样复查采样点间峰值，并在实际 DAC/滤波链验证。本文不声称复现了引用[30]的全部算法或作者原始 LUT；主论文未提供最终九个相位和源代码。

## 3. Adjustable Wideband MCS

论文事实：两个 AD830 DDA 构成镜像电流源，配合公共模式反馈、积分/缓冲和隔直网络；DAC 后为截止约 1 MHz 的六阶椭圆低通。式(1)用参考电压、输出共模与采样电阻描述电流。论文给出测试负载、电流和输出阻抗实验结果。

本项目：有 AD830×2、AD8066、100 Ω 电阻、ADC 电流检测等实际电路，但不能把论文的模拟增益、滤波器、CF→mA 换算、负载能力或实验精度移植成板卡指标。原理图 DAC 页仍写“还需后级滤波电路”；MUX 单电源和模拟信号共模也需核查，详见硬件文档。

## 4. Integer period sampling、FFT 和 CORDIC

正确关系为：

```text
f0 = Fs/N = 5000 Hz
fk = qk Fs/N
N fk/Fs = qk ∈ 正整数
Tcapture = N/Fs = 200 μs
X[m] = Σ(n=0..N-1) x[n] exp(-j 2πmn/N)
Re = Σ x[n]cos(2πmn/N)
Im = -Σ x[n]sin(2πmn/N)
```

**经视觉核对的论文矛盾**：Fig.5 与式(6)印作 `fs=qk fk/N`，与九个频率及 bin 定义不符；式(5)虚部遗漏与式(3)一致所需的负号。实现按上述 DFT 定义及 `fk=qk Fs/N`，不复制错误。

对 `A sin(2πqn/N+φ)`，正频率 bin 为：

```text
X[q] = N A/2 · exp(j(φ-π/2))
Apeak = 2|X[q]|/N
phase_fft = atan2(Im, Re)
phase_sine = wrap(phase_fft + π/2)
```

论文式(8)的 `arctan(Im/Re)`应在工程中用覆盖四象限的 `atan2`。零幅度时相位无效。`2/N` 是非 DC、非 Nyquist 实正弦的峰值幅度因子，RMS 还需除以 √2。

本项目在 PL 对 V、I 都做 FFT，选九个 bin，然后 CORDIC。FFT 的逐级缩放、block exponent、输出位宽和 CORDIC 内部增益必须进入数值契约；不能忽略后直接套 `2/N`。PS 用保存的复数分量求 Z，V/I 相位公共的 `-π/2` 抵消，不需给阻抗相位额外加 π/2。

**周期长度与固定起点区别**：对平稳严格周期信号，从任意起点连续取 N 点也满足整数周期；不同起点改变绝对相位。用户额外要求等待确定的波形周期边界，可保证可重复相位基准，但需额外等待。不能为了达到论文速度而省略此要求。

## 5. Fully Configurable Multiplexer Array

论文：四片 ADG1406，I+/I-/V+/V- 各一路，16 电极；各片同名 Sx 对应同一个电极；每片 4 根地址线，总计 16 根，不是一个 16-bit 单 MUX 地址。

相邻扫描以环形编号，注流 `(n,(n+1)%E)`，测压 `(m,(m+1)%E)`。跳过测压两电极与注流两电极任一重合的组合。每次注流有 `E-3` 个有效测压对；保留方向、不做互易性减半：

`M=E(E-3)`，16 电极为 208，32 电极为 **928**。这是测量组合数量，并非 ADC 物理通道数或频率数。

本项目 ADG732 各片 DB→S 对应不相同，必须四份角色映射，另加独立的物理 E→DB 映射。不能仅扩大地址宽度。

## 6. Measurement timing 与 pipeline

论文 Fig.6：DAC 连续播放；切换/稳定 `ts+tw≈2 μs`；采样 200 μs；200 MHz 流水 FFT/CORDIC 解调约 32 μs。上一帧解调同时开始下一测量的切换/稳定/采样，而非等解调结束再切换。

论文模型：`T=(200+32)×208-(32-2)×207=42046 μs`，约 23.8 个完整扫描/s；其 PC 成像约 20 FPS。这不是 32 电极系统的性能保证。论文[7–10页]报告平均 SNR 56.8 dB（九频率/208组合）；该实验值以及盐水一致性不等于本板验收结果。SNR 重复实验应明确功率/幅度 dB 定义，原文式(16)的口径也不直接照搬。

本项目必须重新预算：双路 FFT、真实 ADG732/模拟链稳定时间、固定周期起点等待、缓存反压和 TCP。见系统文档。必须让 ADC 连续转换，只对稳定后的连续 N 组样点开采集窗口；不可通过随意停 ADC 转换时钟来实现采集间歇。
